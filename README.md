# Healthcare Analytics Patient Flow Dashboard

An interactive Power BI dashboard designed to analyze hospital patient flow metrics, operational bottlenecks, and patient demographics to improve healthcare delivery and resource allocation.

## 📊 Project Overview
Managing patient wait times, bed occupancy, and department efficiency is crucial for modern healthcare providers. This project processes raw hospital operational data to deliver actionable insights into patient journeys from admission to discharge.

## 🛠️ Built With
* **Tool:** Power BI Desktop (`.pbix`)
* **Data Manipulation & Analysis:** Microsoft Excel / CSV
* **Visualization Features:** DAX Measures, Slicers, Interactive Charts, KPI Cards
